# 🍳 Cooking Game (Pygame)

A cozy cooking game where players experiment with ingredients to unlock recipes —
or create cursed dishes if they mess up.

## Features
- OOP-based design
- Recipe unlocking system
- Cursed / secret dishes
- Built with Pygame
